Projeto DIO AI Ebook

## 📒 Descrição
Escrevi uma história baseada em William Shakespeare com os temas programação e romance trágico. 

## 🤖 Tecnologias Utilizadas
Gemini 

## 🧐 Processo de Criação
Pedi para o Gemini criar uma história de romance baseada no escritor William Shakespeare com os temas programação e romance trágico. Após o texto criado, eu pedi para criar uma capa baseada no texto, depois criei um prompt para colocar a imagem como capa e o restante do texto diagramar e criar um arquivo PDF
